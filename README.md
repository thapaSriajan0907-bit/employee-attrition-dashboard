# Employee Attrition Dashboard (Power BI)

## 📊 Project Overview
This project is a **Power BI dashboard** designed to analyze **employee attrition**.  
It provides insights into workforce trends, helping HR teams identify problem areas and improve retention strategies.

---

## 🔹 Key Features
- **KPI Cards**:  
  - Total Employees  
  - Attrition Count  
  - Attrition Rate  

- **Interactive Charts**:  
  - Bar Chart → Attrition by Department  
  - Pie Chart → Attrition by Gender  
  - Line Chart → Attrition by Years at Company  

- **Slicers (Filters)**:  
  - Department  
  - Job Role  
  - Gender  
  - Age (range input)  

- **Theme & Layout**:  
  - Copilot Default Theme for a clean, modern look  
  - Professional layout with KPIs at the top, charts in the middle, and slicers on the right  

---

## 🔹 Tools Used
- **Power BI Desktop**  
- **Excel Dataset** (custom HR attrition data)  

---

## 🔹 How to Use
1. Download the `.pbix` file from this repository.  
2. Open it in **Power BI Desktop**.  
3. Interact with slicers to filter data and explore attrition trends.
